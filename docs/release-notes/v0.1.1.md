Juice Bar 0.1.1: the Mac and Windows apps now look and behave the same, and charging shows properly.

- The charging bolt now shows while the mouse charges on its cable, and stays on while the keyboard charges
- The keyboard % comes back the moment the keyboard wakes, instead of staying blank until the next check
- Rename a device with the pencil next to its switch: the tick or Return saves, the cross or Esc cancels
- The device list shows a mouse or keyboard icon next to each name, on both Mac and Windows
- Windows: the device list no longer shows a "Lowest %" line, since the icon and each row already show it

**Windows:** take `JuiceBar-x64.exe`, or `JuiceBar-arm64.exe` on a Windows on ARM PC, and run it. Windows may show a SmartScreen warning because the program is not code signed yet. Choose **More info**, then **Run anyway**.

**Mac:** take `JuiceBar-mac-arm64.zip`, unzip it and move the app to Applications. There is no version for Intel Macs. macOS blocks it the first time because the app is not signed by Apple. Open **System Settings**, **Privacy & Security**, choose **Open Anyway**, then open it again. Allow **Input Monitoring** when asked: the mouse dongle only answers with it on.
