Juice Bar 0.1.2: it now keeps itself up to date, and Settings has a theme of its own.

- **Check for updates** in General: Launch, Daily (the default), Weekly, Monthly or Never, plus **Check now**. A new version downloads, is checked against its checksum and installs by itself
- **Juice Bar windows** in Appearance: Same as system, Light or Dark
- **Keep windows on top** in Advanced keeps Settings above other apps
- **Reset this page** on Appearance asks first, on the same card as Reset all
- The menu bar and tray icon no longer show a tooltip; the battery card is the only hover view
- Settings is a little larger (720 by 720 on both Mac and Windows)
- Mac: a mouse wheel now scrolls Settings at a normal speed
- Windows: a touchpad now scrolls Settings by how far your fingers move
- Privacy: Juice Bar only connects to GitHub to check for updates. Nothing about you is sent

**Windows:** take `JuiceBar-x64.exe`, or `JuiceBar-arm64.exe` on a Windows on ARM PC, and run it. From this version on, updates install themselves. Windows may show a SmartScreen warning because the program is not code signed yet. Choose **More info**, then **Run anyway**.

**Mac:** take `JuiceBar-mac-arm64.zip`, unzip it and move the app to Applications. There is no version for Intel Macs. macOS blocks it the first time because the app is not signed by Apple. Open **System Settings**, **Privacy & Security**, choose **Open Anyway**, then open it again. Allow **Input Monitoring** when asked: the mouse dongle only answers with it on.
