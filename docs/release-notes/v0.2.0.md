Juice Bar 0.2.0: Bluetooth mice and keyboards, and safer updates.

- **Bluetooth:** any Bluetooth mouse or keyboard that reports its battery now shows its %, next to 2.4 GHz and USB devices. Hover a row to see how it is connected
- A device switched from its dongle to Bluetooth shows once, on the live connection, instead of a second row with an old %
- **Signed updates:** an update installs only if it carries our release signature, and Juice Bar asks before installing (Install or Later). Checking can still be set to Never
- **Try to detect** asks once before it sends a read command to an unknown device, and only talks to devices that declare that command
- Fixed a thin bar that could show under the last row of the menu
- Privacy: Juice Bar connects only to GitHub, to check for updates. Only the app name is sent; GitHub sees your IP address. Nothing else leaves your computer

**Mac:** take `JuiceBar-mac-arm64.zip`, unzip it and move the app to Applications. The app is now signed with our own certificate, so macOS asks once again for **Input Monitoring** and, for Bluetooth devices, **Bluetooth**. If macOS blocks the first launch, open **System Settings**, **Privacy & Security**, choose **Open Anyway**.

**Windows:** take `JuiceBar-x64.exe`, or `JuiceBar-arm64.exe` on a Windows on ARM PC. Windows may show a SmartScreen warning because the program is not code signed by Microsoft. Choose **More info**, then **Run anyway**.
