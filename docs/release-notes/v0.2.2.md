Juice Bar 0.2.2: memory fixes on Mac and Windows.

- Mac: Juice Bar no longer grows in memory over time. Each battery check left about 1 MB behind; it now stays flat
- Windows: fonts used to draw the tray icon % and the device list are now freed, so the app no longer collects font handles over days
- Mac: the menu bar icon and the menu are redrawn only when something changed
- New in the README: how to check your download by hand against the signed list of file fingerprints

**Mac:** take `JuiceBar-mac-arm64.zip`, unzip it and move the app to Applications (or let Juice Bar update itself: it asks first and checks our signature).

**Windows:** take `JuiceBar-x64.exe`, or `JuiceBar-arm64.exe` on a Windows on ARM PC.
